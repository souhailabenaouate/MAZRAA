# 🌱 MAZRA'A – Smart Agricultural Assistance Platform

## About the Project

MAZRA'A is a digital platform designed to help farmers access agricultural information and assistance more easily.

It provides an interface for agricultural diagnosis, farm information, crop rotation guidance, weather information and agricultural assistance.

The platform includes two user roles: **Farmer** and **Technician**, with a multilingual interface.

## Requirements

Before running the project, install:

- **Node.js (LTS version):** https://nodejs.org/
- **Git:** https://git-scm.com/downloads
- A web browser (Google Chrome, Microsoft Edge, Firefox, etc.).

## How to Install and Run MAZRA'A

Follow these simple steps:

**1. Clone the project**

Open CMD or a terminal and run:

```bash
git clone https://github.com/souhailabenaouate/MAZRAA.git
```

**2. Open the project folder**

```bash
cd MAZRAA
```

**3. Install the required dependencies**

```bash
npm install
```

Wait until the installation is complete.

**4. Start the application**

```bash
npm run dev
```

**5. Open the platform**

Open your browser and visit:

http://localhost:5173/

MAZRA'A is now ready to use!

## How to Use the Platform

1. Open the landing page.
2. Click on **Sign Up** to create an account.
3. Enter your information and choose your role (Farmer or Technician).
4. Log in using your newly created account.
5. Explore the different sections and features of the platform.
6. You can change the language and switch between light and dark modes.

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- JavaScript
- Open-Meteo API (Weather Information)

## Important Notes

- An internet connection is required to install dependencies and access live weather information.
- The current version uses local browser storage for account information. It does not require a separate database or backend installation.
- Users should create their own test accounts when exploring the platform.
